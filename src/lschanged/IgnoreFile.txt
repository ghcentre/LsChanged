# This file contains ignore rules for the LsChanged compare report.
#
# To use this file, specify its path as the value of the -i parameter in the compare command, e.g.:
#     lschanged -s /path/to/store compare lp amu /path/to/report -i /path/to/ignorefile -rp /common/path
# 
# The # symbol at the beginning of a line indicates whole line as a comment.
# Empty lines are ignored.
#
# Each non-empty line is a rule with the following format:
#
#     [options=options ]regex=regex
#
#     options       Optional switches to control regular expression matching.
#                   If options are not specified, the defaults are assumed.
#
#     regex         Regular expression string that is matched against each file path
#                   generated by the compare command. File paths that match
#                   any expression are excluded from the report.
# 
# Regex Options:
# 
#     +i or -i      Enables (+i) or disables (-i) case-insensitive matching.
#                   By default, case-insensitive matching is enabled in Windows
#                   and disabled in Linux.
#
# To learn about regular expressions, refer to the documentation at
# https://learn.microsoft.com/dotnet/standard/base-types/regular-expressions
# 
# Before a regular expression match, each file path is transformed as follows:
#
#     * The path is made relative by striping out the -rp parameter value.
#       E.g., if the -rp /absolute/path is specified,
#       /absolute/path/to/file becomes to/file
#
#     * For Windows, backslashes are replaced by forward slashes.
#
# To debug rule matching, specify -v as an LsChanged command-line option.
#
# Examples:
#
# Ignore all .zip files:
# regex=\.zip$
#
# Ignore all files in the logs directory (relative to the root specified in the -rp parameter):
# regex=^logs/
#
# Ignore all files in the bin (Bin, BIN) and obj (Obj, OBJ) directories:
# options=+i regex=^(.*/)*(bin|obj)/
#
