Usage: lschanged command [args] [options]

Common options:
    -s path     Sets store path. The path must be absolute path.

    -v          Outputs actions perfomed to the standard output
                (verbose mode). Error output is always directed to
                the standard error stream.

Commands:
    scan        Scans the folder specified and adds generated snaphot
                to the store.

                Arguments:
                    path        The path to scan. Must be absolute
                                path.

                Options:
                    -fs mode    Follow folder symlinks. Mode is one
                                of the following:
                                    0 - ignore folder symlinks
                                        (default)
                                    1 - follow symlinks but try
                                        to prevent recursion
                                    2 - follow symlinks

                Example:
                    lschanged scan "C:\Starting Path" -fs 1 -s C:\Mystore

    compare     Compares the difference between two snapshots and
                outputs file paths to the specified list file.

                Arguments:
                    mode        Specifies compare mode:
                                    lp  - compare last and previous
                                          snapshots
                                    lf  - compare last and first
                                          snapshots
                                    n,m - compare snapshots with
                                          ordinals n (more recent)
                                          and m

                                For lp and lf modes, compare fails if
                                the store is empty; empty snapshot is
                                assumed if there is one snapshot in
                                the store.

                                For n,m mode, compare fails if one of
                                specified snapshots does not exist.

                    states      Outputs files with the following
                                states (comma-separated):
                                    a - added files
                                    m - modified files
                                    u - unmodified files
                                    d - deleted files

                    listfile    Outputs file paths to listfile specified.
                                File encoding is UTF-8. If listfile name
                                is '-' (dash), standard output stream is
                                used for output. Output encoding is set
                                by the operating system.

                Options
                    -rp folder  Outputs file paths relative
                                (case-sensitive comparation) to the
                                specified folder. Folder must be an
                                absolute path. The folder may not
                                actually exist.

                Example:
                    lschanged compare lp n,m C:\changed.txt -rp "C:\Starting Path" -s C:\Mystore

    list        Lists snapshots in the store.

                Example:
                    lschanged list -s C:\Mystore

    delete      Deletes snapshot from the store.

                Arguments:
                    snapshot    Snapshot ordinal to delete, or
                                'last' to delete the last snapshot.

                Example:
                    lschanged delete 4 -s C:\Mystore
                    lschanged delete last -s C:\Mystore

    clear       Clears the store.

                Arguments:
                    (none)

                Example:
                    lschanged clear -s C:\Mystore
